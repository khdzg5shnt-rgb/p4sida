## 候选稿证明了什么

对混合单侧有限型移位幂和任意有限闭覆盖 K，每条预先固定、间隔趋于无穷的采样 A 都满足：

**全部有限 Borel 细化分割的最小采样计数熵 = 最小最大模式熵 = log N(K)。**

最小子覆盖的有序取差分割明确达到。应用于固定周期 τ、所有安全块共享后继的系统，得到全部合法 Borel 安全选择器、任意 Borel 混合及原子细分的 **Lτ=Mτ=log r/τ**。完整重叠例在 τ=2 时给 (log 3)/2；不要求预装一个全部策略必须读取的非平凡控制字母投影。

边界例有六控制和 r=3，反馈真实改变未来，但全类 **L=M=log 2**。同一反馈给每条 A 的统一上界，连续采样给任意反馈的反向下界。因此 log r 公式的直接推广失败，一般 L=M 没有被反驳。

上述主结果和边界来自已有第 17、18 节；本轮没有扩展其数值或系统范围。稿件另明确给出与 Romagnoli 已知避字覆盖对应的稀疏 Borel 细化缺口，作为同一主定理的直接推论，不包装成新增独立机制。
